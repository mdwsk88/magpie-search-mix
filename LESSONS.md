# Lessons

What earlier changes got wrong, and the rule that would have caught it. Read this before changing code.

Each lesson has the rule, what happened, what to do next time, and the days it was seen.
"Seen" counts separate days: a lesson seen twice on one day is seen on 1 day.
A lesson seen on 3 separate days moves into [docs/acceptance.md](docs/acceptance.md), leaving one line here.

Template:

```markdown
### <one rule that can be checked, written as an instruction>
- What happened: <date> <pull request or commit>: <what was done> → <who it affected, for how long>. Fixed in <pull request or commit>.
- Why: <one sentence about the gap in the process, not about a person>
- Next time: <the check, command or test to add>
- Done right (optional): <date> <pull request or commit>: <what is worth copying>
- Seen: N (YYYY-MM-DD, …)
```
